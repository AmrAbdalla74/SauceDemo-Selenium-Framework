# SauceDemo Selenium Automation Framework

## Project Overview
This project is a Selenium Automation Framework developed using Java, Maven, TestNG, and the Page Object Model (POM). It automates the main user flows of the SauceDemo website.

## Technologies Used
- Java
- Selenium WebDriver
- Maven
- TestNG
- Page Object Model (POM)
- Extent Reports
- TestNG Listeners

## Test Scenarios
- Login
- Add Product to Cart
- Checkout

## Project Structure
```
src
 ├── base
 ├── factory
 ├── listener
 ├── pages
 ├── tests
 └── utils
```

## How to Run

1. Clone the repository
2. Open the project in IntelliJ IDEA
3. Install Maven dependencies
4. Run `testng.xml`
